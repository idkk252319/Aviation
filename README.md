# Aviation 

A website created by aviation lovers for the public. This website has a goal of educating people on the field of aviation. It showcases aircraft families and manufacturers backed by plenty of photos, the best liveries from each continent with a backstory and a picture for each one, and last but not least it goes through some of the worst air disasters that have ever occurred providing video footage of the crashes and an explanatory story. 

## 1. Technologies used: 

   - HTML – for basic website creation. 

   - CSS – for visual aesthetics and UI. 

   - JS – for UX reasons and interactivity. 

   - EmailJS – form creation and gmail support. 

   - Media Query – for responsiveness and versatile design. 

2. Main features: 

   - Introduction to aviation with a few fun facts. 

   - Airplane manufacturers and aircraft families backed by a photo for each and every plane variant and type. 

   - The best looking livery with the best backstory from each continent + a photo and description. 

   - 6 of the worst air disasters ever recorded + video footage and story of how they happened.

4. Project structure: 

This project is made up of 4 HTML files one for each topic, a CSS file for visuals and animations across all pages, and a JavaScript file supporting interactivity.
